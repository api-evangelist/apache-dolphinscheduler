# Apache DolphinScheduler (apache-dolphinscheduler)
Apache DolphinScheduler is a distributed and extensible workflow scheduler platform with a powerful DAG visual interface. It provides rich workflow management capabilities for data pipeline orchestration with support for multiple task types.
